# 🤝 Contributing to GreenHarvest Agriculture

Thank you for your interest in improving this project.

## Contribution guidelines

- Keep `index.html`, `react.js` and `style.css` in the project root unless the loader paths are updated too.
- Use the existing plain-JavaScript React approach; the supplied project does not use JSX or a build system.
- Keep the interface responsive across desktop and mobile screen sizes.
- Preserve the green, soil-brown, gold and cream visual theme unless a design change is intentional.
- Add meaningful `alt` text to informative images.
- Keep keyboard focus visible and consider reduced-motion preferences.
- Do not add API keys, passwords or private credentials to front-end files.
- Clearly identify any feature that needs a backend or external service.
- Verify product information, pricing, contact details and claims before changing public-facing content.

## Suggested workflow

1. Fork the repository.
2. Create a branch for your change.
3. Make one focused improvement at a time.
4. Test the website in a browser at desktop and mobile widths.
5. Check the browser console for errors.
6. Commit your changes with a clear message.
7. Open a pull request describing the change and how you tested it.

## Reporting issues

When reporting a problem, include:

- Browser and operating system.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Relevant console error messages, if any.

## Scope note

The current contact form, newsletter form, review storage and chatbot are front-end demonstrations with the limitations described in the README and `docs/FEATURES.md`. Contributions that add real data processing should include appropriate server-side implementation, security and privacy considerations.
